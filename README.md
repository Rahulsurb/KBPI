# KBPI
A Geospatial Multi-Indicator Framework for Agricultural Resource Prioritization in the Semi-Arid Bundelkhand Region of India

This repository contains the code, methodological documentation, data-processing workflow, and reproducibility materials associated with the Khet Bachao Priority Index (KBPI), a geospatial multi-indicator framework developed for district-level agricultural resource prioritization in the Bundelkhand region of India.

The framework integrates climatic, soil, vegetation, and agricultural-management indicators into a composite Agricultural Resource Index (ARI) and subsequently transforms the ARI into the Khet Bachao Priority Index (KBPI) to identify spatial differences in relative agricultural-resource constraints.

The workflow combines geospatial processing, statistical screening, normalization, Entropy Weight Method (EWM)-based weighting, composite-index construction, spatial classification, and sensitivity analysis.
